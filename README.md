# Khushi's Corner

My personal site: movies, music, sweets, BTS, thoughts and a few tiny games.

Live at **https://khushi-ks1.github.io/personal-page/**

## Post a thought

1. Open https://khushi-ks1.github.io/personal-page/write.html
2. Type your thought and tap **Post it**

It shows up on the site within a minute or two. The first time on a new device, the page walks you through
connecting it with a GitHub token that can only edit this repository (stored only in that browser).

The newest thought shows as a sticky note pinned to the side of the page.

## Music

The player uses free 30-second previews from Apple Music (no files or keys needed).
To add a song you own as a full track, put the mp3 in `audio/` and add `file: "audio/name.mp3"` to that song in `index.html`.

## Add photos

Drop photos into the folders in `images/`. Each folder has a `README.txt` with the file names to use.
