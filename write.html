One-time setup on this device

This lets you post straight from here. You only do it once per phone or laptop.

  1. Open GitHub's "new token" page ↗ Log in if it asks.
  2. Name it thoughts, and set Expiration to No expiration (or a year).
  3. Under Repository access, pick Only select repositories → personal-page.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else alone.
  5. Tap Generate token, copy it (it starts with github_pat_) and paste it here:

The key is saved only in this browser. It can only change files in your site, nothing else on your account. Never share it.
